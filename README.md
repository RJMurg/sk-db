# SK DB

SK DB is my personal template for building SvelteKit applications with databases.
It is the upstream parent of:

- SK-DB-Auth

# Stack

- Svelte 5
- SvelteKit 2
- Prisma 7
- Lucide 1
- Shadcn 1
- Tailwind 4
- Vite 8
- Vitest 4
- Playwright 1
